# RCM Flexure Pivot
This directory contains the files required for 3D printing the KITE pivot (patent pending) and complementary materials ; see the publication at https://doi.org/10.1016/j.mechmachtheory.2026.106645

Link to peer-reviewed article in "Mechanisms and Machines Theory" describing in details the KITE:
https://doi.org/10.1016/j.mechmachtheory.2026.106645
